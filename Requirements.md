# Churn Analysis – Requirements

## Project Overview

The goal of this project is to build an interactive Power BI dashboard that helps understand customer churn and retention.

The dashboard should make it easy to see how many customers are leaving, identify patterns behind churn, and understand which customer groups may need attention.

## What the Report Should Help Answer

The report should help users understand:

- How many customers are currently active?
- How many customers have churned?
- What is the overall churn rate?
- How is churn changing over time?
- Which customer groups have higher churn?
- Which factors may be related to customer churn?
- How does churn affect revenue?
- Which customers or segments may be at higher risk?

## Key Metrics

The dashboard should provide important KPIs such as:

- Total Customers
- Active Customers
- Churned Customers
- Churn Rate
- Retention Rate
- Total Revenue
- Average Revenue

The KPIs should be easy to understand and displayed prominently on the dashboard.

## Churn Analysis

The report should allow users to explore customer churn and identify important patterns.

Users should be able to:

- Compare active and churned customers.
- Analyze churn trends over time.
- Compare churn across different customer segments.
- Identify groups with higher churn rates.
- Understand changes in customer retention.

## Customer Analysis

The report should provide insights into customer behavior.

Users should be able to analyze customers based on the information available in the dataset, such as:

- Customer segment
- Demographics
- Location
- Tenure
- Services or products
- Revenue
- Other relevant customer attributes

## Revenue Analysis

The report should show how customer churn relates to revenue.

Users should be able to understand:

- Revenue from active customers.
- Revenue associated with churned customers.
- Revenue trends over time.
- Which customer groups contribute the most revenue.

## Dashboard Design

The dashboard should have a clean and modern appearance.

It should include:

- Clear KPI cards.
- Modern bar charts.
- Trend charts.
- Simple and easy-to-use slicers.
- Consistent colors.
- Clear titles and labels.
- Good spacing and alignment.
- Minimal visual clutter.

Where useful, **sparklines or small trend indicators** can be used to show changes over time without taking up much space.

## Interactivity

Users should be able to:

- Filter the dashboard.
- Select customer segments.
- Analyze different time periods.
- Interact with charts.
- Compare customer groups.
- Explore churn from different perspectives.

## Expected Result

The final dashboard should provide a simple and clear view of customer churn and retention.

A user should be able to quickly understand the current churn situation and then explore the data to find areas that may require attention.

The dashboard should turn customer data into useful insights that can support better retention and business decisions.

## Deliverables

The project should include:

- Power BI Churn Analysis report.
- Interactive dashboard.
- README documentation.
- Requirements documentation.
- Dashboard screenshot.
