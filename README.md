# Customer Churn Analysis Dashboard

## Overview

A Power BI dashboard designed to analyze customer churn and retention patterns. The report helps identify customer behavior, churn trends, and areas where customer retention can be improved.

## What I Worked On

* Created KPI cards to track key customer metrics
* Analyzed **Total Customers** and **Churned Customers**
* Created **Churn Rate** measures using DAX
* Analyzed customer retention and churn trends over time
* Added interactive slicers for customer and business analysis
* Created visuals to compare active and churned customers
* Designed an easy-to-use dashboard layout
* Used DAX measures to support customer churn analysis

## Analysis

The report looks at:

* Total Customers
* Active Customers
* Churned Customers
* Churn Rate
* Customer Retention
* Churn Trends
* Customer Segments
* Revenue from Customers
* Customer behavior over time
